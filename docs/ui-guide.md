# Краткий UI-гайд
- Основной цвет: тёмно-синий `#14213d`.
- Акцент: синий `#3267e9`; фон: светлый `#f5f7fb`.
- Шрифт: системный sans-serif.
- Сетка: карточки адаптируются под ширину экрана; таблица на телефоне прокручивается горизонтально.
- Формы имеют подписи, фокус-состояния и HTML/серверную валидацию.
