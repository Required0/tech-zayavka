# ТехЗаявка — учебное веб-приложение

Простой сервис заявок техподдержки: регистрация/вход, создание и просмотр заявок, административное изменение статусов.

## Стек
PHP, MariaDB/MySQL, HTML, CSS, JavaScript. Пароли сохраняются в виде хеша; SQL-запросы подготовленные.

## Запуск в XAMPP
1. Запустите Apache и MySQL в XAMPP Control Panel.
2. Скопируйте папку `tech-zayavka` в `C:\xampp\htdocs\`.
3. Откройте `http://localhost/phpmyadmin`, вкладка **Импорт**, выберите `schema.sql`, нажмите **Импорт**.
4. Проверьте настройки БД в `config.php` (стандартно: пользователь `root`, пароль пустой).
5. Откройте `http://localhost/tech-zayavka/`.
6. Зарегистрируйте обычного пользователя.
7. Чтобы назначить его администратором, в phpMyAdmin выберите БД `tech_zayavki`, вкладка **SQL**, выполните запрос, заменив `ВАШ_ЛОГИН` на свой логин:

```sql
UPDATE users SET role = 'admin' WHERE login = 'ВАШ_ЛОГИН';
```

Выйдите и войдите снова. У администратора появится список всех обращений и управление статусами.

## Сущности
- `users`: учётная запись, контактные данные и роль.
- `tickets`: тема, описание, автор, статус и даты.

ER-диаграмма: `docs/er-diagram.md`.

## Сценарии проверки
1. Зарегистрировать пользователя; проверить, что повторный логин отклоняется.
2. Войти и создать заявку.
3. Выйти, войти как администратор и изменить статус заявки.
4. Войти как пользователь и проверить отображение обновлённого статуса.
5. Проверить страницы на узком окне браузера около 390 px.

Это учебная локальная версия. Не размещайте её в интернете без дополнительной настройки безопасности.
